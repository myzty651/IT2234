Basic JavaScript Operations
This repository contains simple JavaScript programs demonstrating basic arithmetic operations and console interactions.

Files
1. Hello.html
This is a basic HTML file that includes JavaScript for displaying messages:

Logs "Hello World" to the browser console.
Displays an alert box with the message "Hello world".
2. BasicOperations.js
This JavaScript file demonstrates fundamental arithmetic operations:

Addition (a + b)
Subtraction (a - b)
Multiplication (a * b)
Division (a / b)
How to Run
Clone the repository:
git clone https://github.com/your-username/repository-name.git
Open Hello.html in a web browser to see the alert and console log messages.
Run BasicOperations.js in a browser console or a Node.js environment:
node BasicOperations.js
Requirements
A web browser (for Hello.html)
Node.js (optional, for running JavaScript files outside the browser)
